# 🧮 Calculator Web App

A simple, responsive, and interactive **Calculator Web App** built using **HTML5, CSS3, and Vanilla JavaScript**.

This project allows users to perform basic arithmetic operations through a clean and user-friendly interface.

## 🌐 Live Website

👉 **[View Live Calculator](https://gulabhussain.github.io/calculator-web-app/)**

## 💻 GitHub Repository

👉 **[View Source Code on GitHub](https://github.com/gulabhussain/calculator-web-app)**

## 📌 About the Project

This Calculator Web App is developed as part of the **OIB-SIP Web Development & Design Internship – Level 2**.

The project was created to practice frontend development concepts, JavaScript logic, DOM manipulation, event handling, and responsive UI design.

## ✨ Features

* ➕ Addition

## 🚀 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/gulabhussain/calculator-web-app.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
